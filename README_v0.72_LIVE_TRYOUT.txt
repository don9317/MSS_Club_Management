v0.72 — K–12 Grade Support

- Grade handling expanded across the live app from K through 12th grade.
- Today’s 1st–6th grade tryout registrations now prepopulate correctly from Program.
- Program parser recognizes:
  Kindergarten / Kinder / K / Grade K
  1st / 2nd / 3rd ... 12th
  Grade 1 / Grade 2 ... Grade 12
  First Grade / Second Grade ... Twelfth Grade
- Grade dropdowns in Setup, Tryout Sessions, Walk-In Registration, and Master Registration are K–12.
- Grade remains editable after import.
- Tryout number prefix supports K as well as numbered grades.
- Existing v0.71 live browser data migrates forward.
