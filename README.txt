MSS Club Management Suite Demo v0.62 — Live Tryout Check-In + Roster Warning

CHECK-IN HEADSHOTS
- Headshot added directly to the Check-In roster.
- Staff can Add/Change/Remove a player's headshot at check-in.
- Mobile/tablet browsers may offer the front camera because the input requests image capture.
- Desktop can select an image file.
- Images are automatically resized to a maximum of 320 px and compressed before saving to reduce browser storage use.
- Check-In metrics now include a Headshots count.

ACTIVE TEAM MINIMUM WARNING
- If a team is activated below its minimum roster, that override is recorded.
- Active Team card shows: "Minimum roster not met — X of Y players."
- The Team Workspace shows the same warning.
- Warning automatically disappears when the roster reaches the required minimum.

Existing v0.61 browser data migrates automatically.
