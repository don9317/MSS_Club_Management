MSS Club Management v0.75 — Post-Tryout Improvements

Implemented from the live tryout:
1. Multi-grade teams: Team Setup supports multiple eligible grades (e.g., 1st/2nd Elite).
2. One-click Check-In: immediate visible refresh after check-in.
3. Persistent global Saved timestamp after state writes.
4. Paper Score Entry:
   - NR (Not Rated) for every category.
   - NR excluded from average.
   - Average displays number of categories rated.
   - Save button visibly changes through Saving and Saved status with timestamp.
5. Paper Packets:
   - NR added to score key.
   - Dynamic recommendation key based on configured/eligible teams.
6. Communication Center:
   - Team-oriented status table with player/offer/acceptance/missing-email counts and last-send status.
7. No-Show Follow-Up:
   - Grade filtering.
   - Email/phone.
   - Contacted checkbox, outcome, notes.
   - CSV export.
8. Full Backup / Restore Club Data JSON added to Registrations.
9. Existing v0.74 live browser data migrates forward.

Note: Camera remains optional; use Upload Photo if webcam behavior is unreliable.
