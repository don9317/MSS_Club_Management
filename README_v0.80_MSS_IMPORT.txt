MSS Club Management v0.80 — Native MSS Registration CSV Import

- Built from v0.79 Simplified Navigation baseline.
- Recognizes native MSS registration exports with a single Participant full-name column.
- Recognizes Current Grade directly, while retaining Grade / Player Grade / Participant Grade / Program compatibility.
- Imports Email and Phone plus native MSS fields including Registered By, Type, Status, Paid, Payment, Signed Up, Most Recent Club Team Name, Current School, Position, Height, Player Skill Level, and Shirt Size.
- Retains support for older CSV files with separate First Name / Last Name fields.
- Adds duplicate protection when the same MSS registration CSV is imported twice.
- Existing v0.79 browser data migrates forward to v0.80.
